# Dispute Resolution Oracle dApp - GenLayer

A Decentralized Dispute Resolution dApp built on the **GenLayer** protocol. This application leverages Intelligent Smart Contracts and LLM-driven consensus to resolve data disputes and claims transparently, neutrally, and automatically.

## 🚀 Key Features
- **Intelligent Smart Contract:** Powered by GenLayer's Python-based contract architecture to execute complex dispute logic.
- **Decentralized Resolution:** Processes conflicting data inputs and determines fair resolutions using consensus mechanisms.
- **Modern User Interface:** Built with React and Vite for a fast, responsive, and intuitive user experience.

## 🛠️ Project Structure
- `contract.py`: The GenLayer Intelligent Smart Contract written in Python.
- `src/`: Frontend React components and application source code.
- `index.html`: Entry HTML document for Vite.
- `package.json`: Project dependencies, scripts, and configuration.
